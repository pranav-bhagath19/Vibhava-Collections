# Vibhava Collections - Premium E-commerce Website

A luxury-level, visually stunning e-commerce experience for a heritage fashion brand selling sarees and dress materials. Built with Next.js, Tailwind CSS, and Framer Motion.

## 🌟 Key Features

- **Premium Design**: Rich maroon and gold aesthetic with elegant typography (Playfair Display).
- **Mobile-First**: Fully responsive and optimized for mobile devices.
- **High Performance**: Optimized images, code splitting, and smooth transitions.
- **Complete Flow**:
  - **Home**: Hero section, category showcase, trending products, and heritage story.
  - **Shop**: Dynamic filtering by price, category, fabric, and occasion. Instant sorting.
  - **Product Detail**: Multi-image gallery, specs list, and related products.
  - **Cart System**: Real-time quantity updates and price calculation.
  - **Checkout**: Guest checkout flow with order summary and success state.
  - **Wishlist**: Save favorites with persistent local storage.
  - **Additional Pages**: About Us, Contact (with WhatsApp CTA), FAQ.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **State Management**: React Context API
- **Fonts**: Playfair Display (Serif) & Inter (Sans-serif) via Google Fonts

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm or yarn

### Installation

1. Clone the repository or extract the ZIP file.
2. Navigate to the project directory:
   ```bash
   cd vibhava-collections
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

To create a production build:
```bash
npm run build
```
To preview the production build:
```bash
npm run start
```

## 📂 Project Structure

- `/src/app`: Application routes and pages.
- `/src/components`: Reusable UI components (Layout, Home, Product, etc).
- `/src/context`: App state management (Cart/Wishlist).
- `/src/data`: Mock product and category data.
- `/src/styles`: Global CSS and design tokens.
- `/public/assets/images`: Optimized brand and product imagery.
